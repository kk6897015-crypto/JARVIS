# JARVIS

Personal AI assistant project.

## Overview
JARVIS is a personal-assistant workspace. Keep application code, configuration, and documentation separated so the repository stays easy to maintain.

## Recommended structure
```
src/          # assistant source code
config/       # non-secret configuration
assets/       # static assets
docs/         # documentation
tests/        # tests
.env.example  # environment variable template
```

## Security
Never commit API keys, passwords, tokens, or private credentials. Store local secrets in `.env` and keep only safe placeholders in `.env.example`.
